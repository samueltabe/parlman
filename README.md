# Reclaiming Respect

Official site for **Emanuel C. Perlman** and the Reclaiming series — rebuilt with Next.js and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Content

Site copy and book data live in `src/data/content.js`. Testimonials are in `src/data/testimonials.json`. Images are served from `public/images/`.
